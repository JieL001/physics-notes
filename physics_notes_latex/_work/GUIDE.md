# 高中物理手写笔记 → LaTeX 转录规范（所有 agent 必读，读一遍即可）

## 0. 背景与总目标
- 原件：一本高中物理**手写笔记本的手机照片**，共 300 页（页码 1–300，下文“全局页码”）。无文字层，只能看图。其中 20 页是别页的完全重复（151–157、201–206、251–257），已被排除，不会分配给你。
- 笔记里有知识点提纲、公式、推导、好题（题干+解答+配图），也夹有少量化学/生物等**非物理**内容。**同一章的内容被零碎地分散在不同页面，甚至同一页里混着好几章**（例如一页里同时有卫星、电表改装、平抛、光学）。
- 最终目标：按章重新汇编成 LaTeX，**每章完整、章与章之间不交叉、内容不丢**。
- 你们现在做第一步：**逐页忠实转录**，并给每一“块”内容打上章节标签，之后由别人按标签汇编。所以：**① 一个字都不要漏；② 章节标签要准；③ LaTeX 要能编译。**

用 Bash 工具运行 python（路径用正斜杠）。**标准流程：**
1. **一次调用准备整个单元**：`python TOOLS/prep.py P1 P2 P3 P4 P5` → 每页生成三张图 `VIEW/pNNN.jpg`（整页总览）、`VIEW/pNNN_a.jpg`（上半，放大）、`VIEW/pNNN_b.jpg`（下半，放大）。图的左边和上边有**红色坐标尺（0~1 的页面比例）**，裁图坐标直接从尺上读。已知横置的页（72、209、239）已自动转正。如果你发现某页仍是横的/倒的，用 `python TOOLS/render.py 页码 --rot 90|270|180`（顺时针度数）自行转正查看，并在块文件的 `%%%PAGE` 行写 `rot=N`；裁图时同样给 crop.py 传 `--rot N`。
2. **逐页读图→立刻写文件**：对每一页，在**同一轮里并行 Read 它的三张图**，然后用 Write 工具直接写出 `PROJ/_work/blocks/pNNN.tex`（格式见 §3）。一页写完再看下一页。小字实在看不清再用 `python TOOLS/crop.py 页码 x0 y0 x1 y1 名字 --zoom` 放大（输出 `VIEW/zoom_名字.jpg`，再 Read）——只在需要时用，不要对每页都放大。
3. **配图在块里用 `%FIG` 行声明**（见 §4），**不要**单独调用 crop。所有页写完后**一次调用**：`python TOOLS/crop_batch.py --blocks PROJ/_work/blocks/pA.tex PROJ/_work/blocks/pB.tex …`（把本单元所有页文件都列上）→ 自动裁出全部配图，并输出“联系表”图路径（`CONTACT SHEET: …jpg`）。**Read 联系表（一次看完所有图）**，检查：图是否完整、标注/箭头是否被切、是否带进大段无关文字。有问题就用 Edit 改对应 `%FIG` 行的坐标，再运行同一命令。
4. **一次调用编译检查**：`python TOOLS/texcheck_all.py PROJ/_work/blocks/pA.tex PROJ/_work/blocks/pB.tex …` → 必须 `ALL OK`（有错就改再跑）。
5. 最后回复**不超过 5 行**：`DONE pages=…, blocks=N, figs=M, unclear=K, 以及最需要二次核对的 1~3 处`。不要贴转录内容。
**禁忌**：不要逐页单独 render；不要对每页做多次放大；不要反复 Read 同一张图；不要为已转好的页再做“第二遍”阅读（复核由别人做）。

## 3. 输出文件格式（每页一个文件 `PROJ/_work/blocks/p{3位全局页码}.tex`）
```
%%%PAGE 195 rot=0 legibility=good summary=本页一句话概述
%%%BLOCK id=195-01 ch=05 sec=同步卫星·相遇周期 kind=problem alt=none cont=none y=0.03-0.22
...这一块的 LaTeX 正文...
%%%END
%%%BLOCK id=195-02 ch=10 sec=电表改装·欧姆表 kind=problem alt=none cont=none y=0.22-0.50
...
%%%END
%%%PAGEEND 195
```
- 块头里是 `key=value`，**sec 尽量不含空格**（用 `·` 或 `_`）。
- `id`：`{3位页码}-{序号两位}`，序号按页面阅读顺序。`ch`：见上表。`sec`：该块所属的**小节名**（中文，简短；同一主题在不同页要用同样的名字，参考上表括号里的小节名）。
- `kind`：`knowledge`（知识点/结论）｜`formula`（公式汇总）｜`method`（方法技巧/模型）｜`problem`（题目+解答）｜`derivation`（推导）｜`diagram`（主要是图）｜`summary`（提纲/思维导图）｜`note`（批注/易错/小贴士）｜`misc`。
- `exp=1`（可选）：实验类内容。`alt`：涉及的其它章编号，逗号分隔，没有写 `none`。`cont`：从上一页接续而来写 `prev`，下页还会接着写写 `next`，两者都有 `both`，否则 `none`。`y`：这块在页面里纵向的大致范围（0~1，可直接从坐标尺读）。
- **一块 = 一个相对独立的内容单元**（一道题连同解答和配图是一块；一组相关公式是一块；一幅提纲图是一块）。一页通常 2–10 块。**所有块合起来必须覆盖该页的全部手写内容。**
- 空白页：只写 `%%%PAGE` 行（加 `blank`）和 `%%%PAGEEND` 行（若有零星字迹仍要转）。

## 4. 转录与 LaTeX 约定
**保真第一**：写什么转什么，不增、不删、不改写、不“润色”、不补充你自己的知识。可以整理版面，但信息要全。
- 中文直接写。公式用 `$...$`；独立成行/多行推导用 `\[ ... \]` 或 `\begin{align*}...\end{align*}`；分数 `\frac`/`\dfrac`；上下标、`\sqrt`、`\sum`、`\int` 等照常。
- **希腊字母和数学符号必须放在数学模式里**：α→`$\alpha$`，∴→`$\therefore$`，≈→`$\approx$`，∝→`$\propto$`，≤≥→`$\le\ge$`，⇒→`$\Rightarrow$`，⊥∥→`$\perp\parallel$`，°→`$^\circ$`，✓→`$\checkmark$`。文本模式里可以直接用：中文、①②③…⑩、★☆○●■□△、`·`、`±×÷`、`←↑↓→`。
- 单位：`$5\unit{m/s}$`、`$\unit{kg\cdot m/s}$`；核素：`$\nuc{238}{92}{U}$`；微分符号 `\dd`；自然常数 `\ee`；矢量 `\vec{v}`；`\overrightarrow{AB}`。
- 列表：`itemize/enumerate`（可嵌套 3 层）。手写的大括号分支、思维导图用嵌套列表还原层级，并保留箭头（`$\to$`、`$\Rightarrow$`）。表格用 `tabular`（有 booktabs、diagbox）。
- 可用的盒子环境（见 `PROJ/preamble.tex`）：`keybox`（被框起来/特别强调的重点，`\begin{keybox}[标题]`）、`notebox`（易错/注意）、`problem` + `solution`（题目与解答）：
  ```
  \begin{problem}[来源或编号，可省略]
  题干……（含已知条件）
  \begin{solution}
  解答步骤……
  \end{solution}
  \end{problem}
  ```
  笔记里只有题干没有解答，或只有解答没有完整题干，都照实转，不要编造缺的部分。
- **红笔/彩色批注**：`\red{…}`。**辨认不清的字**：`\unclear{你的最佳猜测}`（完全无法辨认写 `\unclear{…}`）。**被划掉的字**：`\struck{…}`。整块被大叉/斜线划掉的内容：照样转录，并在块首加注释 `% 原稿此块被划去`。
- 手写里明显的**笔误/物理上不对的地方**：**照原样转录**，不要擅自改；在该处末尾加注释 `% CHECK: 说明`（后面统一汇总核对）。
- 忽略：纸张页眉 `Date. NO.`、边缘的行号 5/10/15…、笔记本背面透过来的**淡淡的反字**、照片里的桌面/手/其它物品、相邻页边缘。
- 块内不要使用 `\section/\subsection/\chapter` 等分节命令；块内小标题用 `\textbf{…}`。
- 不要使用公共导言区里没有的宏包/命令（没有 `cancel`、`physics`、`mhchem`、`circuitikz`）。需要划掉用 `\struck`。化学式用 `$\mathrm{H_2O}$` 之类。
- **配图**：任何示意图（受力图、电路图、轨迹图、光路图、实验装置、图像曲线）都要用 `%FIG` 声明并用 `\notefig` 插入，放在对应位置：
  ```
  %FIG p195_a 0.12 0.33 0.42 0.52
  \notefig[0.3]{figures/p195_a.png}
  ```
  `%FIG 图名 x0 y0 x1 y1`：坐标是**页面比例**（从图上的红色坐标尺读，左上角为原点；x0<x1，y0<y1），要把整幅图连同标注框全，少带无关文字。图名固定 `p{3位页码}_{a,b,c…}`。`\notefig[宽度比例]`：宽度大致取“这张图在原页中的宽度比例”，限制在 0.25–0.85。图中的文字标注已在图里，不必重复转录；图旁/图下的独立文字和公式要转录。图和相关文字放同一块。**不要自己用 TikZ 重画。**

## 5. 完成前自检（写每页文件时就做，不要事后再读一遍）
1. 页面上每个角落都覆盖了吗（页边、页脚、行间小字、箭头旁小注、红笔字）？
2. 每个数字、下标、指数、正负号都核对了吗（手写最容易看错：`1/l`、`0/6`、`v/γ/r`、`t/+`）？拿不准就用 `\unclear{}`。
3. 每幅图都写了 `%FIG` 和 `\notefig` 吗？
4. 每块的 `ch`/`sec`/`kind` 填了吗？章号合理吗？
5. `texcheck_all.py` 返回 `ALL OK`。
